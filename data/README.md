# Data policy

The original SABI Excel export is intentionally excluded from version control.

## Reasons

- The source database may be subject to licensing restrictions.
- The export contains company and shareholder information.
- The search metadata may include user information.
- Redistribution is not required to demonstrate the analytical methodology.

## Public reproducibility

The repository will include one of the following:

1. an anonymized sample with fictional company identifiers; or
2. a fully synthetic dataset preserving the original schema.

The public sample must not contain real shareholder names, user credentials
or information that allows reconstruction of the licensed source dataset.
